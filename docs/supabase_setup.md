# Hướng dẫn thiết lập Supabase Database

Để dự án hoạt động với Supabase, bạn cần tạo hai bảng `players` và `scores` trong cơ sở dữ liệu Supabase của bạn. 

Hãy truy cập vào trang quản lý dự án Supabase, chọn mục **SQL Editor** và chạy đoạn script SQL dưới đây để khởi tạo cấu trúc bảng:

```sql
-- 1. Tạo bảng người chơi (players)
CREATE TABLE IF NOT EXISTS public.players (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name text UNIQUE NOT NULL,
    secret text NOT NULL DEFAULT '',
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Thêm index để tối ưu truy vấn theo tên người chơi
CREATE INDEX IF NOT EXISTS idx_players_name ON public.players (name);

-- Nếu bảng đã tồn tại, thêm cột secret bằng lệnh sau:
-- ALTER TABLE public.players ADD COLUMN IF NOT EXISTS secret text NOT NULL DEFAULT '';


-- 2. Tạo bảng điểm số (scores)
CREATE TABLE IF NOT EXISTS public.scores (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    game_id text NOT NULL,
    player_name text NOT NULL REFERENCES public.players (name) ON DELETE CASCADE,
    score double precision NOT NULL,
    metadata jsonb DEFAULT '{}'::jsonb NOT NULL,
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Thêm index tối ưu hóa cho truy vấn bảng xếp hạng (leaderboard)
CREATE INDEX IF NOT EXISTS idx_scores_game_score ON public.scores (game_id, score);
```

## Cấu hình Biến Môi Trường (Environment Variables)

Sau khi tạo bảng thành công, hãy lấy thông tin **Project URL** và **API Key (anon or service_role)** từ phần **Project Settings > API** trong Dashboard của Supabase và cấu hình như sau:

### Chạy Local (Local Development)
Tạo file `.env` ở thư mục gốc của dự án:
```env
SUPABASE_URL=https://<your-project-id>.supabase.co
SUPABASE_KEY=<your-supabase-service-role-or-anon-key>
```

### Triển khai Vercel (Production)
Thêm các biến môi trường sau trong phần cấu hình của dự án trên Vercel:
- `SUPABASE_URL`
- `SUPABASE_KEY`
